# Peridot ID PRD

## Vision
Peridot ID is a Gaming Identity Platform providing Authentication, Identity, and Profile for the Peridot ecosystem.

## Scope v1 (Foundation)
- Google Login
- JWT + Refresh Token
- Identity
- Profile
- JavaScript SDK

## Non-goals
- Wallet
- Blockchain
- NFT
- Friends
- Inventory
- Achievements

## Success Metrics
- Single identity across products
- >99.9% login success

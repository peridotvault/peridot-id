---
title: JavaScript SDK
description: The official Peridot ID SDK for the browser
---

The SDK (`@peridot/sdk-js`) wraps the API for browsers. It sends credentials with every
request, so the API's cookies are handled automatically.

## Install

```bash
npm install @peridot/sdk-js
```

## Initialize

```ts
import { Peridot } from '@peridot/sdk-js';

const peridot = Peridot({
  baseUrl: 'https://api.peridot.id',
  onUnauthorized: async () => {
    // Access token expired — try to refresh silently before redirecting to login
    const ok = await peridot.auth.refresh();
    if (!ok) {
      await peridot.auth.login(); // redirects the browser to Google
    }
  },
});
```

## Sign in

`auth.login()` redirects the browser to Google. The user signs in and is sent back to
`CLIENT_SUCCESS_URL` with the session cookies already set.

```ts
await peridot.auth.login();
```

## Identity

```ts
const me = await peridot.identity.me();
// { id: "pid_01K4Y4DWMK7YSH8X4JQY9M4T6P", status: "active", createdAt: "2026-08-03T13:30:00.000Z" }
```

### Login credentials

```ts
const credentials = await peridot.identity.credentials();
// [{ id: "3f9c...", provider: "google", email: "a@b.com", linkedAt, lastLoginAt }]

await peridot.identity.unlinkCredential(credentials[0].id); // true if unlinked
```

Unlinking the identity's last credential fails (returns `false`) — every identity must
keep at least one way to log in.

## Profile

```ts
const profile = await peridot.profile.me();
// { id, identityId, username, usernameChangedAt, displayName, avatarUrl, locale, createdAt, updatedAt }

const updated = await peridot.profile.update({
  username: 'peridotplayer',
  displayName: 'PeridotPlayer',
  locale: 'en-US',
});
```

Usernames are lowercase `[a-z0-9_]`, 3–20 characters. `update` returns the API error
object if the username is already taken.

## Wallet

Each identity can have **one wallet** — a Solana address associated with the PID. Custody is
**record-only**: Peridot never generates, holds, or returns any key material.

```ts
const wallet = await peridot.wallet.me();
// { id, chain: "solana", address, status: "active", createdAt }
// or ApiError { statusCode: 404 } when the PID has no wallet

const created = await peridot.wallet.create("2nBoE7F2vLkGtvXh7QnUhvW5mYPbRmY8GXJqPz9tKcQ");
// { id, chain: "solana", address, status: "active", createdAt }
```

- Creating again returns the **existing** wallet — a PID can never have more than one.
- The wallet belongs to the PID, not to Google (or any other provider). Unlinking a
  credential leaves it untouched, and logging in from another device does not change it.
- `create` returns the API error object on validation failure (`400`).

## Log out

```ts
await peridot.auth.logout();
```

## Refreshing

Usually you never call `refresh()` directly — the `onUnauthorized` callback does it. If
you need to force a refresh:

```ts
const ok = await peridot.auth.refresh(); // true if a new session was issued
```

## Errors

Methods return the API error object instead of throwing for failed requests:

```ts
const result = await peridot.profile.me();
if ('statusCode' in result && result.statusCode === 401) {
  // handle unauthenticated
}
```

See [Errors](/docs/errors) for the full error contract.

Peridot ID is a **Gaming Identity Platform** for the Peridot ecosystem. It provides
Authentication, Identity, and Profile so every Peridot product shares a single user
account.

## What you get

- **Authentication** — provider sign-in with secure, rotating sessions
- **Identity** — a stable PID for each user across all products (`pid_<ULID>`, never changes)
- **Profile** — per-user profile data (`username`, `displayName`, `avatarUrl`, `locale`)

## Key facts

| Fact | Value |
|---|---|
| API versioning | All endpoints are under `/v1` |
| Identity ID | `pid_<ULID>` — permanent, never changes |
| Login credentials | `(provider, providerUserId)` is unique; email is metadata only |
| Authentication | `HttpOnly` cookies (JWT access token + rotating refresh token) |
| Access token lifetime | 15 minutes |
| Refresh token lifetime | 30 days (rotated on every use) |
| Spec | [OpenAPI 3.0](/docs/api) — also served by the API at `GET /v1/openapi.yaml` |

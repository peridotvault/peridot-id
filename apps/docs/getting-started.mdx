## Prerequisites

- Node.js 20+
- A registered app (`client_id` starting with `pidapp_…`) — see
  [Sign in with PeridotID](/sign-in-with-peridot-id#1-register-your-app). Localhost
  works without one.
- The browser SDK for app code:
  ```bash
  npm install @peridotvault/pid-sdk-js
  ```

That is the whole setup: `Peridot({ clientId })` resolves every host by itself.
**There is no API URL, base URL, or environment variable to configure** — app code
never sets a host, and `baseUrl` exists only for [self-hosting](/self-hosting).
Loopback (`localhost`/`127.0.0.1`) is always accepted, so local development needs no
allowed-origins entry either.

## Versioning

The API is versioned through the URL path (`/v1/...`). Breaking changes ship as a new
major version; the previous version stays available until it is deprecated.

## Your first request

Almost every endpoint requires an authenticated session. The quickest way to verify the
API is reachable is the login endpoint, which returns the Google sign-in URL:

```bash
curl -X POST https://api.peridot.id/v1/auth/login
```

```json
{ "url": "https://api.peridot.id/v1/auth/google" }
```

Open `url` in a browser and sign in with Google. You are redirected back with the session
cookies set. From then on, use a cookie jar for all requests:

```bash
# Save the session cookies (browser already set them; for non-browser clients use -c)
curl -b cookies.txt https://api.peridot.id/v1/identity/me
```

```json
{
  "id": "ifal@pid",
  "status": "active",
  "createdAt": "2026-08-03T13:30:00.000Z"
}
```

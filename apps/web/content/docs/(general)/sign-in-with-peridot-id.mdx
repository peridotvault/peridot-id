---
title: Sign in with PeridotID
description: Let users sign into your app with their PeridotID (Google or passkey)
---

Add "Sign in with PeridotID" to any web app in three steps. Your users authenticate
against PeridotID production — no local setup, no secrets to manage.

## 1. Register your app

Call `POST /v1/apps` with your PeridotID session (cookie) to get a public `client_id`.
List every URL PeridotID may return users to — codes are only issued to these:

```ts
import { Peridot } from '@peridotvault/pid-sdk-js';

const peridot = Peridot({ baseUrl: 'https://api.pid.peridotvault.com' });
// Register with just a name — allowed origins are managed after, in the dashboard
// at pid.peridotvault.com/workspace (or PATCH /v1/apps).
const res = await peridot.post('/v1/apps', { name: 'My Game' });
// res.data.clientId → "pidapp_..." — pass it as client_id in step 2
```

Then add your websites under **Allowed origins** (bare `https://…` origins, no paths).
Pass the exact return URL in code — its origin must be listed:

Your redirect URI origins are automatically allowed for browser API calls (within
~60s of registering, no redeploy needed). Local development needs nothing at all:
`http://localhost`, `http://127.0.0.1` and `http://[::1]` (any port, any path) are
always allowed — arbitrary production hosts are never accepted without registration
(an open redirect would let anyone steal users' login codes).

## 2. Open the login popup

```bash
npm install @peridotvault/pid-sdk-js
```

```ts
import { Peridot, openLoginPopup } from '@peridotvault/pid-sdk-js';

const peridot = Peridot({
  baseUrl: 'https://api.pid.peridotvault.com',
  solanaRpcUrl: 'https://api.devnet.solana.com',
  popupBaseUrl: 'https://app.pid.peridotvault.com',
});

async function signIn() {
  const { pidCode } = await openLoginPopup({
    popupBaseUrl: 'https://app.pid.peridotvault.com',
    params: {
      redirect_uri: window.location.origin,
      origin: window.location.origin,
      popup: 'login',
      client_id: 'pidapp_...',
    },
  });
  if (pidCode) {
    const identity = await peridot.auth.exchange(pidCode, 'pidapp_...');
    // { pid, profile: { displayName, avatarUrl }, credentials: [{ provider, email }] }
  }
}
```

Both Google and passkey ceremonies run inside the popup on the hosted PeridotID
login with the address bar visible — Google needs the redirect round-trip,
WebAuthn legally requires a PeridotID origin, so no ceremony can run inside your
page. When popups are blocked, fall back to navigating to the hosted login
directly (same params as the URL query). No API calls happen before login, so
there is nothing CORS-related to configure.

In React, wrap the same two calls in your own button + hook — there is no
provider component to install.

## 3. Handle the login

After login the popup returns a one-time `pid_code` (full-page fallback:
PeridotID redirects back to your `redirect_uri` with it). Exchange it as above
— directly, or via your backend, which then mints your app's own session.

Already logged in? The hosted page shows a one-tap consent screen asking to allow
your website to sign in with the visitor's PeridotID — instead of another login.
Denying returns to your `redirectUri` with `?error=access_denied`.

Prefer to mint your own session? Exchange server-side instead of calling
`peridot.auth.exchange` in the browser:

```ts
// your backend: verify the code against PeridotID, then create your session
const r = await fetch('https://api.pid.peridotvault.com/v1/auth/exchange', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({ code, clientId: 'pidapp_...' }),
});
const identity = await r.json(); // single-use code, 5-minute expiry
```

## Notes

- Passkey login always runs on a PeridotID-hosted page (browsers bind WebAuthn to our
  domain) and returns with `pid_code` like Google does.
- Codes are single-use, expire in ~5 minutes, and are bound to your `client_id`.
- No framework? The snippet in step 2 is already framework-free: `openLoginPopup`,
  `loginWithPasskey({ clientId, returnTo })` (auto-delegates to the popup),
  `exchange(code, clientId)`.
